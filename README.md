# doqo: a language agnostic documentation generator

Doqo is based on Tree-sitter and aimes to be an easily extensible language agnostic documentation generation tool through Tree-sitter grammars. You can generate neat documentation for multi-language projects without hassle.

## Features

- **Intuitive command-line interface**: generate and server documentation locally from your terminal
- **Language plugins**: support for multiple languages through plugins
- **Minimalistic web interface**: read and search your documentation in your browser
- **Markdown support for comments**: format your comments with Markdown
